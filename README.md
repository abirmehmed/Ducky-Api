# 🦆 QuackTrack API

Backend for my Khaki Campbell duck farm — 34 layers + 11 upcoming.

## Endpoints
- `GET / POST /api/eggs` — daily egg log
- `GET / POST /api/expenses` — feed & medicine costs
- `GET / POST /api/sales` — egg sales income
- `GET / POST /api/flock` — flock groups (laying / upcoming)
- `GET /api/stats` — today's eggs, 7-day avg, lay rate %, monthly profit

## Run
npm install
node server.js   # 🦆 kitchen open on port 4001
